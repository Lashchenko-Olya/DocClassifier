# Система автоматичної категоризації документів (NLP)

Програмне забезпечення для автоматичної класифікації службових документів (Накази, Заяви, Листи) з використанням алгоритмів машинного навчання (Наївний байєсівський класифікатор).

## Реалізований функціонал (згідно з ТЗ):
1. **Графічний інтерфейс:** Створено зручний web-UI (Dark Academia style) для взаємодії користувача з моделлю.
2. **Валідація та підказки:** Реалізовано перевірку на порожнє введення, виведення повідомлень про помилки в інтерфейсі.
3. **Обробка помилок та логування:** Усі дії (успішна класифікація, старт сервера) та помилки записуються у файл `./logs/app.log`. Запобігання падінню сервера реалізовано через блоки `try...catch`.
4. **Збереження даних:** Після тренування, ML-модель автоматично зберігається у файл `classifier_model.json` для подальшого відновлення.
5. **Зовнішня конфігурація:** Налаштування (порти, шляхи до файлів) винесено у зовнішній файл `config.json`.
6. **NLP:** Використано стемінг `PorterStemmerRu` для розпізнавання кирилиці.

## Як запустити:
1. Встановити залежності: `npm install natural express`
2. Запустити сервер: `node server.js`
3. Відкрити в браузері: `http://localhost:3000`
